# Site — Dra. Bruna Amazonas Aloise

Site estático (HTML/CSS/JS), sem build. Publique via GitHub Pages (Settings → Pages → branch `main`, pasta raiz).

## Fotos reais
O site usa ilustrações próprias como base. Para usar fotografias reais, coloque os arquivos em `assets/img/` com estes nomes; elas passam a aparecer automaticamente por cima das ilustrações:
`hero.jpg`, `consultorio.jpg`, `galeria-1.jpg` a `galeria-4.jpg` (proporção do hero: 3:4).

## Pendente de confirmação
Logo oficial, redes sociais, CRO, link do perfil de avaliações (hoje abre uma busca no Google Maps) e lista de procedimentos.
